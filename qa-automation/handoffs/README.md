# Handoffs

One tab per session. At the end of each tab, write `handoffs/<YYYY-MM-DD_HHMM>-<tab>.md`
(never overwrite an earlier one) and start the next tab in a fresh session.

Each handoff says:

- where the session stopped
- what is still running or left in the app (records created, settings changed)
- which decisions are open, and who owns them
- the exact next step, as a command or a prompt
